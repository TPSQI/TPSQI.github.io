CSS 布局十年记：从 float 到 Grid

木质脚手架发布于 2026 年 8 月 12 日阅读约 3 分钟

翻旧项目是一件残酷的事。2016 年写的 CSS 还躺在硬盘里，像一层一层的地质断层，记录着每个时代的「最佳实践」。

第一代：float 时代的「伪布局」

最早做页面，布局全靠浮动。

.col-left  { float: left;  width: 200px; }
.col-right { float: right; width: 300px; }
.clearfix::after {
  content: '';
  display: table;
  clear: both;
}

float 本是为文字环绕设计的，被硬拉来搭框架，代价是：

  • 父元素高度塌陷，必须 clearfix；
  • 源码顺序和视觉顺序经常对不上；
  • 自适应宽度要靠百分比 + 负 margin 手算。

那几年前端的口头禅是「清浮动」，像老师傅的口头禅是「敲两下」——都是在给工具的缺陷打补丁。

第二代：display: table 的幻觉

短暂流行过一阵用 display: table 模拟表格布局，等高侧栏确实是刚需。但 HTML 语义被滥用，维护起来像在 CSS 里手写 <table>，很快被抛弃。

第三代：Flexbox——一维布局的解放

2015 年前后 Flexbox 得到主流浏览器支持，我第一次感受到布局是「设计出来的」而不是「凑出来的」：

.nav {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
}

gap 的出现更是里程碑——再也不用给中间元素加怪异的 margin。垂直居中从玄学变成了一行代码。

Flex 解决了一维问题：导航、按钮组、卡片内排列。但一到二维的页面框架，还是得靠嵌套 flex 硬撑——「外层 row、内层 column」的俄罗斯套娃，写起来依旧憋屈。

第四代：Grid——二维布局的正解

Grid 把「行」和「列」提升为一等公民：

.page {
  display: grid;
  grid-template-columns: 1fr 300px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "main   aside"
    "footer footer";
  gap: 24px;
}

最震撼的是 grid-template-areas——布局直接用「画表格」的方式写出来，代码即图纸。响应式也不再需要一堆魔法数字，改一行 grid-template-columns 就完成桌面到移动的切换。

四代同堂的启示

现在我的项目里，四代技术各有分工：

场景首选
页面级框架Grid
组件内部排列Flex
文字环绕float（本职工作）
真表格数据table（不要抗拒它）

技术史读多了会发现一个规律：每一代布局方案，都在消灭上一代的「补丁文化」。而补丁消失的地方，就会生长出新的抽象。

写在最后

前几天带新人，他问我现在是不是只学 Grid 就够了。

我说：你要知道 clearfix 为什么存在，才能真正感激 gap。

了解暗伤，才知道新方案好在哪里——这也是我偶尔回头翻旧 CSS 的原因。
