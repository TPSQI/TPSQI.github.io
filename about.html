这个博客是什么

这是一个纯静态的个人博客：没有框架、没有服务端依赖，可部署在任意静态托管（GitHub Pages、Netlify、Cloudflare Pages、Nginx 等）之上，打开即读。

它既是作品，也是方法论的示范——用最朴素的 HTML / CSS / JavaScript，把一个博客「该有的所有内容」搭起来：文章列表与分页、详情页与目录、分类、标签、归档、全文搜索、暗色模式、阅读进度、留言本，一样不少。

内容方向

  • 技术——前端、工程化与开发中的手艺活；
  • 随笔——关于思考、工作方式与自我整理；
  • 阅读——读书笔记，以及书与现实的互相照亮；
  • 生活——桌面、周末、咖啡与一切具体的事。

名字的由来

脚手架是临时的，木头是温的。它从不假装自己是建筑的一部分——大楼封顶后就会被拆走，运往下一个工地。这个名字提醒我：少一些炫技，多一些能站人的结构；先把当前这层搭稳，让别人能站上来干活。

更完整的版本，可以读 《为什么我给自己取名「木质脚手架」》。

技术说明

  • 纯静态多页面站点，文章页已预渲染，无 JavaScript 也能阅读正文；
  • 正文以 Markdown 存于 js/articles.js，由自研轻量解析器渲染；
  • 主题偏好保存在浏览器 localStorage，跨页保持深浅色一致；
  • 响应式布局，桌面与手机均可阅读；支持快捷键 Ctrl / ⌘ + K 唤起搜索。
